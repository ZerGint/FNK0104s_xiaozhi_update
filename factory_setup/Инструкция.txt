# FNK0104S — инструкция по прошивке и FNKMusicBridge

Эта папка предназначена для первичной полной прошивки FNK0104S и настройки локального музыкального моста.

Состав папки:

- `factory_bin/fnk0104s-factory-1.1.15-external_amp-merged.bin` — полный образ для устройства с внешним усилителем.
- `factory_bin/fnk0104s-factory-1.1.15-internal_amp-merged.bin` — полный образ для устройства со встроенным усилителем.
- `FNKMusicBridge-1.1.6.zip` — переносимый FNKMusicBridge для компьютера.

## Образы прошивки и совместимость

В папке `factory_bin` находятся два полных merged-образа FNK0104S версии 1.1.15. Выбирайте образ по установленному усилителю:

- `factory_bin/fnk0104s-factory-1.1.15-external_amp-merged.bin` — для устройства с внешним усилителем MAX98357A по I2S.
- `factory_bin/fnk0104s-factory-1.1.15-internal_amp-merged.bin` — для устройства со встроенным усилителем.

Перед прошивкой определите, какой усилитель используется на вашей плате. Не прошивайте `internal_amp` на устройство с внешним усилителем и не прошивайте `external_amp` на устройство со встроенным усилителем: это разные варианты конфигурации звука и OTA-совместимости. Оба файла являются полными образами для записи с адреса `0x0`.

После установки full-образа устройство получает поддержку выбора OTA-обновления по варианту усилителя. Для внешнего усилителя используется ветка `external_amp`, для встроенного — `internal_amp`. Не переименовывайте эти файлы и не меняйте вариант при последующих обновлениях.

## 1. Полная прошивка через ESP Tool в браузере

Удобнее всего использовать официальный web-инструмент Espressif:

`https://espressif.github.io/esptool-js/`

Подойдут Chrome или Edge с поддержкой Web Serial.

1. Скачайте выбранный full-образ из раздела «Образы прошивки и совместимость».
2. Закройте монитор последовательного порта и другие программы, которые могут занять COM-порт устройства.
3. Подключите FNK0104S к компьютеру USB-кабелем с передачей данных.
4. Откройте web-инструмент и нажмите подключение к последовательному порту. Выберите COM-порт платы USB Serial/JTAG.
5. Добавьте скачанный файл прошивки и укажите адрес `0x0`.
6. Для FNK0104S используйте параметры флеширования: ESP32-S3, 16 MB, DIO, 80 MHz. Если инструмент уже определил эти параметры, проверьте их перед запуском.
7. Нажмите Flash/Start и дождитесь завершения записи и проверки.
8. Отключите и снова подключите USB либо нажмите RESET.

Если порт не появляется, удерживайте BOOT, кратко нажмите RESET, отпустите BOOT после появления устройства и повторите подключение в браузере. Иногда требуется другой USB-кабель или прямой USB-порт компьютера.

Полный merged-образ записывается с адреса `0x0` и содержит загрузчик, таблицу разделов, приложение, OTA-разделы и заводские данные. Такая прошивка заменяет содержимое флеш-памяти, включая сохранённые настройки Wi-Fi и NVS. После неё устройство нужно настроить заново. Для обычного обновления через OTA полный образ не используется: OTA применяет файл из OTA-репозитория.

## 2. Первоначальная настройка устройства

1. После полной прошивки включите устройство и дождитесь запуска Wi-Fi.
2. Если сохранённой сети нет, устройство поднимает точку настройки. Подключитесь к показанному SSID, откройте страницу настройки и укажите домашнюю сеть и пароль.
3. Убедитесь, что устройство получило IP-адрес и компьютер с FNKMusicBridge находятся в одной локальной сети.
4. После настройки устройство само пытается найти FNKMusicBridge через mDNS. Если автоматическое обнаружение не сработало, задайте адрес моста командой `music.set_bridge_url`, например `http://192.168.31.153:8765`.

## 3. Что такое FNKMusicBridge

FNKMusicBridge — локальная программа-прокси и каталог для музыкальных функций XiaoZhi. Она запускается на Windows-компьютере и принимает запросы устройства по локальной сети. Стандартный порт — `8765`.

FNKMusicBridge не является самим генератором музыки. Для генерации он передаёт задание настроенному провайдеру, например WangP или Yue2, принимает результат и хранит его локально. Для поиска и скачивания обычных пользовательских MP3 провайдер генерации не нужен: достаточно запущенного моста и доступной локальной сети.

## 4. Запуск и настройка FNKMusicBridge

1. Распакуйте `FNKMusicBridge-1.1.6.zip` в папку без кириллицы и лишних ограничений доступа.
2. Запустите `FNKMusicBridge.exe`.
3. Проверьте состояние моста в браузере: `http://127.0.0.1:8765/`.
4. Если используется WangP, проверьте его страницу: `http://127.0.0.1:7860/`.
5. Настройки провайдера находятся в соответствующей папке `providers/*/config`.
6. В брандмауэре Windows разрешите входящие локальные подключения для `FNKMusicBridge.exe` или для TCP-порта `8765`. mDNS также не должен блокироваться сетевым профилем.
7. Для ручной проверки IP компьютера откройте адрес вида `http://IP_КОМПЬЮТЕРА:8765/` с устройства или из другой машины в той же сети.

Основные каталоги моста:

- `data/music_library` — обычные MP3 пользователя;
- `data/generated` — временные/полученные файлы генерации;
- `data/library` — каталог и метаданные сгенерированных треков;
- `data/jobs.json` — состояние заданий генерации;
- `data/logs` — логи моста;
- `ffmpeg` — вспомогательные компоненты обработки аудио.

## 5. Какие команды ИИ выполняет через FNKMusicBridge

Команды относятся к MCP-инструментам устройства. Долгие операции запускаются в фоне; не нужно вызывать одну и ту же команду в цикле.

| Команда | Назначение |
|---|---|
| `music.generate` | Запустить одну генерацию песни по названию, стилю и полному тексту. ИИ после вызова сообщает, что генерация началась. |
| `music.generation_status` | Один раз проверить состояние текущего задания: генерация, готово или локально. При готовности может потребоваться подтверждение скачивания. |
| `music.download_ready` | Запустить скачивание уже готового результата генерации с моста на устройство. |
| `music.search_library` | Найти сгенерированные треки в библиотеке моста. При нескольких совпадениях ИИ уточняет выбор. |
| `music.download_library` | Скачать выбранный сгенерированный трек в `/sdcard/generated_music`. |
| `music.search_user_library` | Найти MP3, которые пользователь положил в `data/music_library`. |
| `music.download_user_library` | Скачать выбранный пользовательский MP3 в `/sdcard/music`. |
| `music.play_generated` | Воспроизвести сгенерированный трек, уже находящийся в `/sdcard/generated_music`. |
| `music.set_bridge_url` | Задать ручной URL моста для диагностики. Пустое значение возвращает автоматический поиск через mDNS. |

Типичный цикл генерации:

1. ИИ вызывает `music.generate` один раз.
2. FNKMusicBridge ставит задание провайдеру генерации.
3. Позже ИИ вызывает `music.generation_status` один раз и сообщает результат.
4. Когда трек готов, ИИ просит разрешение на скачивание, затем вызывает `music.download_ready`.
5. После завершения файл можно воспроизвести через `music.play_generated`.

Типичный цикл для существующего трека:

1. `music.search_library` — поиск сгенерированного трека или `music.search_user_library` — поиск пользовательского MP3.
2. После выбора одного результата — соответствующая команда скачивания.
3. Воспроизведение выполняется локальным медиаплеером устройства. Обычные SD-команды `media.search_sd` и `media.play_sd` остаются отдельными и также работают с локальной музыкой.

Сгенерированные файлы на устройстве хранятся в `/sdcard/generated_music`, пользовательские MP3 — в `/sdcard/music`. FNKMusicBridge не отправляет эти файлы через интернет между устройством и компьютером: передача идёт по локальной сети.

## 6. Пользовательский каталог музыки

1. На компьютере запустите FNKMusicBridge.
2. Скопируйте обычные MP3 в `data/music_library` внутри распакованной папки моста.
3. Сохраните файлы с понятными именами и дождитесь индексации.
4. Попросите ИИ найти песню в пользовательской библиотеке. Он использует `music.search_user_library`.
5. После выбора ИИ вызывает `music.download_user_library`; файл попадёт на SD-карту устройства в `/sdcard/music`.
6. После скачивания песня доступна обычному локальному плееру и может запускаться через `media.play_sd`.

Для этого сценария не требуется включать WangP, Yue2 или другой генератор. Нужны только запущенный FNKMusicBridge, доступный TCP-порт `8765`, одна локальная сеть и MP3 в `data/music_library`.

## 7. Если мост не находится

- Проверьте, что процесс `FNKMusicBridge.exe` запущен и отвечает на `http://127.0.0.1:8765/`.
- Проверьте IP компьютера и доступность `http://IP_КОМПЬЮТЕРА:8765/`.
- Разрешите FNKMusicBridge в брандмауэре Windows для частной сети.
- Убедитесь, что устройство и компьютер не разделены гостевой Wi-Fi сетью, VPN или изоляцией клиентов.
- Задайте ручной адрес командой `music.set_bridge_url`.
- Для генерации дополнительно проверьте доступность и настройки выбранного провайдера. Для пользовательских MP3 провайдер не нужен.

Не закрывайте FNKMusicBridge во время поиска, генерации, скачивания или индексации. При удалении файлов из `data/music_library` повторите индексацию и поиск.
