# FNK0104S custom firmware release 1.1.5

- `fnk0104s-firmware.bin` is the ESP32-S3 application image for the `freenove-fnk0104s` board.
- `firmware-info.json` contains the image checksum and build metadata.
- This release targets the v2 partition layout with the `assets` partition.

The same image is attached to the [v1.1.5 OTA release](https://github.com/ZerGint/FNK0104s_xiaozhi_update/releases/tag/v1.1.5).
