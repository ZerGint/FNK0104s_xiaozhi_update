# FNK0104B custom firmware release 1.1.25

- fnk0104b-firmware.bin — FNK0104B (2.8-inch ILI9341, onboard amplifier, internal_amp).

Listed in ota/stable-fnk0104b.json. FNK0104B has no external-amplifier variant.
This is the first B release with an update channel: B boards on 1.1.24 or earlier must be flashed
once over USB with the full 1.1.25 image; later releases arrive over the air.
