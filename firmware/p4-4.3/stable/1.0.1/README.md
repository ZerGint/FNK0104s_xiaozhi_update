# Waveshare ESP32-P4 4.3" custom firmware release 1.0.1

- RU/p4-4.3-firmware.bin — Waveshare ESP32-P4-WIFI6-Touch-LCD-4.3 (Rev3.x, Multi-OTA layout),
  Russian build. Application image only, installed into the inactive XiaoZhi slot (OTA0/OTA1).

Listed in ota/stable-p4-4.3.json under the `RU` key.

Changes since 1.0.0:

- Interface labels in Russian: navigation (Дом, Радио, Музыка, Погода, Настройки), assistant
  status, "Сейчас играет", player states, Треки / Созданные, empty-list messages.
